# FORMÉ — storefront

Static responsive storefront for the FORMÉ first edit.

## Files
- `index.html` — storefront structure and product catalogue
- `styles.css` — responsive visual identity
- `script.js` — collection filters, product enquiry modal, copy-to-clipboard

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch `main` and folder `/ (root)`.
4. Save. GitHub Pages will provide the public URL after deployment.

## Important launch notes
- Product imagery currently loads from No Love Society's CDN, based on the brand owner's permission stated by the project owner.
- Some selected sub-variants are shown with a collection reference image until their exact product image is supplied/verified. These are marked in the catalogue.
- iPhone model options are enquiry fields only. Compatibility for each case/model combination must be confirmed with the supplier before accepting payment or confirming an order.
- The enquiry form copies a message; it does not process payments or store customer data.
- Replace social/contact links and add verified prices, delivery terms, returns policy and business details before public sales.
