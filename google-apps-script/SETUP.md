# Подключение заявок FORMÉ

Таблица: https://docs.google.com/spreadsheets/d/1Qk5Svjxv-1O2FC2e24zcxnXebKVme0KN6P0DRTgbDmo/edit?usp=drivesdk

Подготовленный проект Apps Script: https://script.google.com/home/projects/1Sz-bEwH1xvdIknjOrG8WbAN6jtI5DTIaD-qIBrT4Mg6MJRAm-kVEek0T/edit

Статус: код сохранён, развёртывание не завершено. Автоматическая проверка остановила настройку доступа. Публичный адрес обработчика ещё не получен. Рабочий сайт не обновлён.

После подтверждения доступа:
1. Развернуть Code.gs как веб-приложение, выполняемое от имени владельца. Для приёма запросов сервером сайта требуется доступ «Все». Сама таблица остаётся закрытой. doGet не читает заявки.
2. Просмотреть и подтвердить разрешения Google на работу с таблицами.
3. Сохранить адрес /exec в переменной Vercel GOOGLE_ORDERS_ENDPOINT.
4. Опубликовать изменения из ветки connect-orders.
5. Отправить явно помеченную тестовую заявку через сайт; проверить строку в таблице и отсутствие дубля при повторе того же orderId.

Обработчик api/orders.mjs подтверждает запись, проверяя JSON-ответ Google. Запрос без подтверждения не показывает клиенту успех. ID заявки сохраняется для повторной попытки. Согласие, контакт и остальные обязательные поля проверяются на сервере. Цена и название товара берутся из каталога. Apps Script экранирует формулы в текстовых полях.
